Backpropagation in an expression graph

g256×155 4.25 KB

Perform backpropagation through this graph using the rules:

if node.op == "add":
    a, b = node.inputs
    a.grad += node.grad
    b.grad += node.grad
elif node.op == "mul":
    a, b = node.inputs
    a.grad += node.grad * b.value
    b.grad += node.grad * a.value
