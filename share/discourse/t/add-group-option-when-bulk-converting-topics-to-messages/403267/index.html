Add Group option when bulk converting Topics to Messages

nathank

It is great that we can now bulk convert Topics to Messages (and vice-versa) - hurray!!!

This works really well when converting Messages → Topics, where you get this nice little modal which allows you to specify the category (and control notifications):

image592×255 5.23 KB

However, it isn’t so flash in the reverse direction. As you can see, the modal only allows notification control:

image592×186 5 KB

This means that the Message includes any participants, but nobody else. This is great for truly private conversations, but not so good for my use case of converting a Category into a Group Inbox.

Adding an option to include group(s) to the resultant Messages would markedly extend this functionality.
