When content localization is enabled, tag icons break because the component matc…hes on `tag.name` which gets translated. This switches iconTagRenderer to match on tag.slug instead. Slugs are not translated, and matches the actual description of the setting as well.

edit: testing now and indeed this is the case - if you change the tag slugs in this component from underscore to dash (don’t change the tag names themselves), it should work again.
