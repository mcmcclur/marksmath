Undeleting a post does not create a log entry

RGJ

Deleting a topic → creates staff action log entry “delete topic”
Deleting a post → creates staff action log entry “delete post”

Restoring a topic → creates staff action log entry “un-delete topic”
Restoring a post → does not create a staff action log entry

So if a post is being restored, you have to revert to the system log files to find out who did it.
